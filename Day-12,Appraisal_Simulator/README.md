# Python Appraisal Simulator : 🥜 or 🍭 

A fun and relatable Python GUI project that simulates corporate appraisal outcomes — inspired by the classic “Peanut vs Lollipop” reality (Credit : naukridotcom) 😄

## What This Project Does

This application takes simple inputs like:
	•	Self rating (1-5)
	•	Manager’s vibe (Good/Okay/Bad)
	•	Company revenue (Yes/No)

### and predicts your appraisal result as:
	•	🎉 Lollipop (Good Hike)
	•	🥜 Peanut (Low/No Hike)

---

## Logic: 

The decision is based on a combination of:
	-	High self-rating (≥ 4)
	- Manager’s vibe (Good/Okay)
	- Company revenue performance

### If conditions are favorable → Lollipop 🍭 Otherwise → Peanut 🥜

---

## Libraries Used

1. tkinter
   - Used to build the GUI (Graphical User Interface)
	 - Handles buttons, labels, input fields, dropdowns

2. PIL (Pillow)
   - Used for image processing
	 - Loads and resizes images (peanut & lollipop)

	2.	Run the script:

---

## How It Works (Step-by-Step)
	1.	User enters:
	- Self rating (1–5)
	- Manager vibe
	- Revenue status
	2.	On clicking “Check Appraisal”:
	- Function appraisal() runs
	- Conditions are evaluated
	- Result is decided
	3.	Output:
	- Text message shown
	- Image (🥜 or 🍭) displayed
