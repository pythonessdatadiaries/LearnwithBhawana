# AI Engineer Roadmap (0 to Job-Ready in 3-4 Months)

Follow in order. Don't skip steps.

## Roadmap

**Month 1**
- Wk 0: Setup — Install Python + VS Code. YouTube: freeCodeCamp, CodeWithHarry. roadmap.sh/python
- Wk 1-2: Python — variables, loops, functions, OOP
- Wk 3-4: Math — Linear Algebra, Probability, Stats (basics only)

**Month 2**
- Wk 1: Data — NumPy + Pandas
- Wk 2-3: ML — Regression, Classification, Trees (scikit-learn)
- Wk 4: Projects — build 2 (price predictor, spam classifier)

**Month 3**
- Wk 1: Deep Learning — Perceptron → CNN → RNN (intuition only)
- Wk 2: Framework — pick PyTorch OR TensorFlow
- Wk 3: LLMs — Transformers, Prompt Engineering, Fine-tuning
- Wk 4: Build — chatbot or RAG app using OpenAI/Claude API

**Month 4**
- Deployment — Docker + Streamlit/FastAPI → Render or HuggingFace Spaces

## Tips
- Build > watch tutorials
- Google/Claude when stuck — normal
- Post progress publicly for accountability
- Start applying after Month 3, don't wait to "feel ready"

## Free resources
Python: freeCodeCamp, CodeWithHarry · Math: 3Blue1Brown, Khan Academy · ML: Kaggle Learn · DL: PyTorch tutorials · LLMs: docs.claude.com · Deploy: Streamlit docs
