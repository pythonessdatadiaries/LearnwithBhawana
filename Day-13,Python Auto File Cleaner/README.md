
# 🧹 Python Auto File Cleaner (OS + Shutil)

Tired of a messy Downloads folder? 😩  
This simple Python project automatically organizes your files into folders like PDFs, Images, Docs, etc.

---

## 🚀 What This Project Does

- Scans your Downloads folder
- Detects file types (.pdf, .jpg, .docx, etc.)
- Creates folders automatically (if not present)
- Moves files into respective folders

👉 Example:
- PDFs → /PDFs
- Images → /Images
- Docs → /Documents

---

## 🧠 Concepts Used

- os module → to interact with system
- shutil module → to move files
- loops & conditions → to filter files
